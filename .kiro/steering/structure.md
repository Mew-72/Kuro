# Repository structure

```
KURO/
├── app/                          # Next.js App Router
│   ├── layout.tsx                # Loads Cubism core script — do not move
│   ├── page.tsx                  # Mounts <KuroDesktop> with ssr: false
│   └── settings/page.tsx         # Standalone settings window route
│
├── components/
│   ├── kuro/
│   │   ├── kuro-desktop.tsx      # Character + ticker + state machine + Tauri events
│   │   ├── kuro-settings-menu.tsx# Inline menu component (legacy; the /settings page is canonical)
│   │   └── kk.tsx                # Sandbox/scratch — do not import from production paths
│   ├── lines.tsx                 # All dialogue. Tsundere voice lives here.
│   ├── theme-provider.tsx
│   └── ui/                       # shadcn/ui primitives — generated, edit sparingly
│
├── hooks/                        # use-mobile, use-toast (shadcn defaults)
├── lib/utils.ts                  # cn() helper
│
├── public/model/                 # Live2D assets — do not rename files
│   ├── LittleCat.model3.json     # Entry point loaded by pixi-live2d-display
│   ├── LittleCat.moc3
│   ├── LittleCat.physics3.json
│   ├── LittleCat.cdi3.json
│   ├── LittleCat.2048/texture_00.png
│   └── motions/*.motion3.json    # Reference only — NOT played at runtime (see animation.md)
│
├── src-tauri/
│   ├── tauri.conf.json           # Two windows: `main` (transparent overlay) + `settings`
│   ├── capabilities/default.json # All required permissions; add new perms here
│   ├── Cargo.toml
│   └── src/
│       ├── lib.rs                # App setup, polling thread, event emission cadence
│       ├── commands.rs           # AppState + #[tauri::command] surface
│       ├── context.rs            # KuroContext + KuroProfile structs (frontend contract)
│       ├── activity.rs           # classify_activity() — the judgement engine
│       ├── typing.rs             # rdev listener, rolling-window WPM, last-input timestamp
│       ├── idle.rs               # IdleTracker FSM (Sleeping / Wandering / Returned)
│       ├── health.rs             # CPU/RAM/battery + threshold alerts
│       ├── session.rs            # Daily session counters + milestone firing
│       └── profile.rs            # JSON persistence for KuroProfile (kuro-profile.json)
│
└── .github/workflows/build.yml   # Windows-only Tauri build pipeline
```

## Where new things go

| Adding... | Goes in... |
| --- | --- |
| A new dialogue category | `components/lines.tsx` as a named export, then dispatch in `kuro-desktop.tsx` |
| A new Kuro state | `KuroState` union in `kuro-desktop.tsx` + a `case` in the master ticker |
| A new Rust event | Emit from the polling thread in `lib.rs`, listen in `kuro-desktop.tsx`'s setup `useEffect` |
| A new Tauri command | Add to `commands.rs`, register in `invoke_handler!` in `lib.rs`, also list permission in `capabilities/default.json` if a built-in plugin |
| A new milestone | `session.rs` for fire logic, `lines.tsx` for the line, `kuro-desktop.tsx` listener for `kuro:milestone` |
| A new setting | `KuroSettings` interface in `kuro-settings-menu.tsx`, the settings page UI, and a consumer in `kuro-desktop.tsx` |
| A new keyboard shortcut | The `shortcuts` map inside the `onKeyDown` handler in `kuro-desktop.tsx` |

## Files that should NOT be casually edited
- `app/layout.tsx` — the Cubism core `<script>` must load here, ahead of the React tree.
- `public/model/*` — file names are referenced by `LittleCat.model3.json` and the Cubism runtime.
- `components/ui/*` — generated by shadcn; treat as vendored.
- `next.config.mjs` — `output: "export"` is required for Tauri bundling.
